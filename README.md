# Offboard Kit

A free IT onboarding and offboarding checklist generator. Pick "new hire" or "employee leaving", tick the systems your company uses, and get a printable, step-by-step checklist.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to run it.

- `data.js`: the checklist steps for each system (edit this to add or change steps)
- `app.js`: form handling, checklist rendering, copy and print
- `style.css`: styles, including light/dark and print layout

## Hosting

Any static host works. Cloudflare Pages or GitHub Pages are free: point them at this repository with no build command.
